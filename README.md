# MALIK — Portfolio

Personal portfolio of **Malik**, a web engineer based in Japan.
Built with **100% vanilla HTML, CSS, and JavaScript** — no frameworks,
no libraries, no build tools.

**Live site:** https://marikudev.github.io

日本語の説明は下部にあります。

## About

I made a career change from hospitality to web engineering. Working
face to face with customers on the front line taught me how to
understand what people truly need — that experience is now the
foundation of how I build products.

This site is bilingual (Japanese by default, with an English toggle)
and was designed and built by hand as a learning project: every
layout, animation, and interaction is plain CSS and JavaScript.

## Features

- Bilingual interface (Japanese / English) with an instant toggle
- Project showcase carousel with autoplay, drag/swipe, and keyboard support
- Scroll-spy navigation and a spotlight cursor effect
- Fully responsive, with reduced-motion support for accessibility
- Project covers drawn as hand-written SVG illustrations

## Tech Stack

- HTML5, CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (ES6, no dependencies)
- Hosted on GitHub Pages

## Project Structure

```
.
├── index.html   # Page structure and content
├── style.css    # All styling (design tokens live in :root)
├── script.js    # All behaviour and content data (bilingual)
└── assets/      # Background photo, SVG project covers, favicon
```

## Run Locally

No build step is needed. Clone the repository and open `index.html`
in a browser — or, for the best result, serve the folder with any
static server, for example VS Code's Live Server extension.
